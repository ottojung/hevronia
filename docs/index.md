# Welcome

This documentation site is powered by **Docusaurus**.

Хевронія is a Telegram bot (see [@hevronia_bot](https://t.me/hevronia_bot)) built
with grammY, LangChain, and an OpenAI chat model. Each private Telegram chat has
its own persistent conversational thread backed by a local SQLite database.

See the repository [`README`](https://github.com/ottojung/hevronia) for setup,
configuration, and development instructions.
